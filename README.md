# CareerCenter Android releases

Public APK downloads for the CareerCenter mobile app.

## Latest install

Scan with your phone. It starts the APK download directly (Android may ask you to allow "Install unknown apps" for your browser):

[![Scan to download the APK](https://raw.githubusercontent.com/careercenter-am/careerapp-releases/main/assets/qr.png)](https://github.com/careercenter-am/careerapp-releases/releases/latest/download/CareerCenter.apk)

Or tap **[Download the latest APK](https://github.com/careercenter-am/careerapp-releases/releases/latest/download/CareerCenter.apk)**, or open the **[latest release page](https://github.com/careercenter-am/careerapp-releases/releases/latest)**.

| | |
|---|---|
| **Latest APK (direct)** | [CareerCenter.apk](https://github.com/careercenter-am/careerapp-releases/releases/latest/download/CareerCenter.apk) |
| **Update manifest** | [version.json](https://github.com/careercenter-am/careerapp-releases/releases/latest/download/version.json) |
| **Package** | `am.careercenter.app` |

There is **one** install QR (`assets/qr.png`). It encodes the fixed link `releases/latest/download/CareerCenter.apk`, so it never needs regenerating: every release must include an asset named exactly `CareerCenter.apk` (a copy of the versioned APK), and the QR then always downloads the newest build.
